================================================================================
                    💡 LỆNH CƠ BẢN
================================================================================

START:
    .\demo-all.ps1                    # Tự động
    docker-compose up -d              # Thủ công

CHECK:
    docker-compose ps                 # Status
    docker-compose logs -f            # Logs
    curl http://localhost:5000        # Test

SECURITY:
    .\security-scan.ps1               # Chạy scans
    Get-ChildItem reports\            # Xem reports

STOP:
    docker-compose down               # Stop container

CLEANUP:
    docker-compose down -v            # Stop + xóa volumes
    docker system prune -a -f         # Xóa tất cả

================================================================================
                    🐛 TROUBLESHOOTING
================================================================================

Vấn đề: Container không chạy
Giải pháp:
    docker logs football-app
    docker-compose down
    docker-compose build --no-cache
    docker-compose up -d

Vấn đề: Port 5000 bị chiếm
Giải pháp:
    netstat -ano | findstr :5000
    taskkill /PID <PID> /F

Vấn đề: Trivy not found
Giải pháp:
    choco install trivy -y
    (PowerShell as Administrator)

Vấn đề: Docker Desktop không chạy
Giải pháp:
    Mở Docker Desktop
    Đợi icon xanh
    Chạy lại: docker-compose up -d

================================================================================
                    🎓 KIẾN THỨC DEVSECOPS
================================================================================

DevSecOps = Development + Security + Operations

Workflow:
    Code → Build → Test → Scan → Deploy → Monitor

Security Tools:
    - Bandit: SAST (Static Application Security Testing)
    - Safety: Dependency vulnerability scanning
    - Trivy: Container image scanning

CI/CD:
    - GitHub Actions: Automated pipeline
    - Security gates: Block if vulnerabilities found
    - Auto deploy: To cloud platforms
