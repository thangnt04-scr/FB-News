## ⚠️ IMPORTANT NOTES

### **Free Tier Limitations:**
- ⚠️ Service sleeps after 15 minutes of inactivity
- ⚠️ Cold start takes 30-60 seconds
- ⚠️ 750 hours/month free (enough for 1 service 24/7)
- ⚠️ Ephemeral filesystem (data lost on restart)

### **Database:**
- 📁 Location: `/tmp/footballinfor.db`
- ⚠️ SQLite database (ephemeral)
- ⚠️ Data lost on service restart
- ⚠️ Data lost on redeploy
- 💡 For production: Migrate to PostgreSQL

### **Auto-Deploy:**
- ✅ Enabled on push to `cicd-pipeline` branch
- ✅ Triggered automatically by GitHub webhook
- ⏱️ Deployment takes ~2-3 minutes

## 🔧 TROUBLESHOOTING

### **Service Not Responding:**
```
1. Check Render Dashboard → Service status
2. View Logs tab for errors
3. Check if service is sleeping (free tier)
4. Wait 30-60 seconds for cold start
```

### **Deployment Failed:**
```
1. Check Logs tab for build errors
2. Verify build.sh is executable
3. Check requirements.txt for missing dependencies
4. Verify environment variables are set
```

### **Database Errors:**
```
1. Check logs for "Initializing database" message
2. Verify db.init_db() is called on startup
3. Check /tmp is writable
4. Redeploy to recreate database
```
